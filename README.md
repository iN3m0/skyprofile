# SkyProfile

SkyProfile is a desktop app for viewing your Hypixel Skyblock stats. Look up any player, pick one of their profiles, and see their skills, collections, inventory, pets, and more. It also has calculators that help you find the cheapest way to upgrade things.

## How to install it

1. Go to the [Releases page](https://github.com/iN3m0/skyprofile/releases/latest).
2. Download the file named something like `skyprofile-setup.exe`.
3. Run the downloaded file and follow the installer.
4. Windows may show a warning because the app isn't signed. Click "More info" then "Run anyway" to continue.

Once it's installed, you can open SkyProfile from your desktop or Start menu like any other app.

## Getting your API key

The app needs a personal Hypixel API key to look up player data. This only takes a minute:

1. Go to [developer.hypixel.net](https://developer.hypixel.net) and log in with your Hypixel account.
2. Create a new API key.
3. Copy the key.
4. Open SkyProfile, go to Settings, and paste the key in.

Your key is saved only on your own computer and is never shared with anyone.

## What you can do with it

- Look up any player and see their full Skyblock profile: skills, collections, inventory and armor, pets, slayers, dungeons, minions, and more.
- Use the MP Calculator to see the cheapest accessory upgrades for Magical Power.
- Use the Attribute Calculator to see what shards you need and the cheapest way to level up your attributes.
- Use the Museum Calculator to see the cheapest items to donate for museum experience.
- Use the SkyBlock XP Calculator to see the cheapest way to gain Skyblock levels overall.

Switching between tools keeps the same player and profile selected, so you don't need to search again each time.

## Updates

SkyProfile checks for new versions on its own and updates itself in the background. You don't need to do anything to stay up to date.
